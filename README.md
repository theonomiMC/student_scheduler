# East-West University Student Schedule

A simple web app for browsing the class schedule of [East-West University](https://eastwest.edu.ge/en/) for semesters I-VI: classes, rooms, professors and times.

**Live site:** https://student-scheduler-psi.vercel.app/

> Unofficial student project, not affiliated with East-West University.

## Features

- Class schedule for semesters I-VI
- Room, professor and time details
- Works on desktop and mobile

## Tech stack

- Next.js
- Supabase (database)
- Vercel (hosting)
